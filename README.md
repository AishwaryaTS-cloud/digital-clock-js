# Digital Clock

A simple **Digital Clock web application** built using **HTML, CSS, and JavaScript**.
It displays the current time, day, and date in real time and allows switching between **12-hour and 24-hour formats**.

## Live Demo

Open the project here:
👉 https://AishwaryaTS-cloud.github.io/digital-clock-js/

## Features

• Real-time clock updating every second
• Shows current day and full date
• Toggle button for **12-hour / 24-hour** format
• Clean centered UI with gradient background
• Lightweight and built with **pure JavaScript**

## How It Works

The application uses JavaScript's **Date object** to retrieve the current system time.
The clock updates every second using `setInterval()`.

The toggle button switches the display between:

• **12-hour format (AM/PM)**
• **24-hour format**
